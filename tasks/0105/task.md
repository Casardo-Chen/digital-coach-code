## Task Name
Illustrate a Flower Vase in Figma

#### Task Description
Create a transparent glass vase, design a flower from repeated petal shapes, and place curved stems inside the vase.

#### Learning Objectives
- Build an illustration from basic shape layers.
- Use gradients, opacity, blur, and shadows to create depth.
- Combine shapes using boolean operations.
- Apply the glass effect to create a translucent vase.
- Use transforms.
- Edit vector points and corner radius to customize shapes.
- Use the Pen and Bend tools to create natural curved stems.

#### Initial State
Empty Figma Design file.

#### Final Outcome
A completed flower vase illustration with transparent glass vase, a flower with curved stems, layered petals, texture effects, and realistic glass distortion. See the reference image.
