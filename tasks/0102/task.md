## Task Name
Create a Loading Animation in Figma

#### Task Description
Create a reusable loading animation in Figma using frames, ellipses, Smart Animate, prototype connections, and component variants. The animation should loop through multiple loading states and be usable as an instance inside a mobile app screen.

#### Parameters:
- Shape: four ellipses
- Ellipse size: 24 × 24 initially, 60 × 60 in final state
- Prototype trigger: After delay
- Delay: 100ms
- Animation: Smart Animate
- Animation duration: 300ms
- Custom Bézier curve: 0.5, -0.1, 0.5, 1.1

#### Learning Objectives
- Create and organize frames for animation states.
- Use ellipse shapes, alignment guides, and Smart Selection to arrange objects evenly.
- Duplicate and modify frames to create different animation states.
- Use prototype connections with After Delay and Smart Animate.
- Create a looped prototype animation.
- Convert multiple frames into a reusable component set.
- Create and test an instance of the loading animation in a new frame.

#### Initial State
Empty Figma Design file.

#### Final Outcome
A looping loading animation made from four animated dots, organized as a reusable Figma component set and placed as an instance inside a mobile screen. See the reference image.
