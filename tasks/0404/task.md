## Task Name
Add Effects in FL Studio Mixer

#### Task Description
Add effects to instruments in FL Studio using the Mixer. The task introduces how to route Channel Rack instruments to Mixer inserts, apply and adjust effects, send multiple instruments through the same effect chain, and understand special Mixer inserts such as Master and Current.

#### Learning Objectives
- Understand how Channel Rack instruments connect to Mixer inserts.
- Use the Mixer to add, open, close, and adjust effects.
- Apply common effects such as reverb, delay, chorus, and low-pass filtering.
- Route one or more instruments to the same Mixer insert.
- Automatically assign instruments to free Mixer tracks.
- Understand the role of special Mixer inserts such as Master and Current.
- Use visual monitoring effects such as WaveCandy during playback.

#### Initial State
Beat, melody, and Playlist arrangement already created.

#### Final Outcome
An FL Studio project where selected instruments are routed to Mixer inserts with effects applied, including a melody instrument with a delay effect and a Master insert using WaveCandy to visualize playback.
