## Task Name
Make a Base Donut Mesh with Icing in Blender

#### Task Description
Create a base donut model with icing in Blender from an empty file. Use basic viewport navigation, mesh primitives, Edit Mode, modifiers, and Sculpt Mode to build an organic donut shape and a separate icing mesh with dripping details.

#### Learning Objectives
- Navigate the Blender 3D viewport.
- Move, rotate, and scale objects in the scene.
- Create basic mesh primitives and choose an appropriate starting shape.
- Edit mesh geometry by selecting, moving, deleting, and extruding vertices or edges.
- Use modifiers to deform, thicken, and smooth mesh objects.
- Use Sculpt Mode to refine the model and create a more organic shape.

#### Initial State
Empty Blender file.

#### Final Outcome
A donut model with a donut mesh and an icing mesh that includes smooth dripping details. See the reference image.
