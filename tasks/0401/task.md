## Task Name
Make a Beat in FL Studio Channel Rack

#### Task Description
Create a basic beat using FL Studio’s Channel Rack and pattern-based workflow. The task introduces how to browse and add sounds, build a drum pattern, adjust channel organization and mix settings, create a longer pattern, add a bass line, and arrange patterns in the Playlist.

#### Learning Objectives
- Understand FL Studio’s pattern-based workflow.
- Use the Channel Rack to build and preview rhythmic patterns.
- Browse, add, remove, organize, mute, and solo sounds.
- Adjust basic channel properties such as name, color, volume, and panning.
- Extend a pattern beyond one bar.
- Create a simple bass line using an instrument and the Piano Roll.
- Arrange multiple patterns in the Playlist and switch between Pattern Mode and Song Mode.

#### Initial State
Empty FL Studio project.

#### Final Outcome
A short FL Studio song arrangement containing at least two patterns: a main beat with drums and bass, and an intro pattern with a different drum beat, arranged in the Playlist and playable in Song Mode.
