## Task Name
Add Sprinkles to Donut Icing in Blender

#### Task Description
Add sprinkles to an existing donut model in Blender using procedural generation.

#### Learning Objectives
- Create simple mesh objects to use as sprinkle shapes.
- Use modifiers or geometry nodes for procedural object scattering.
- Assign generated instances to custom sprinkle meshes.
- Adjust scatter parameters such as density, scale, rotation, and randomness.
- Control where generated objects appear on a surface.
- Use weight paint as an optional mask for more targeted sprinkle placement.

#### Initial State
Blender file with a donut and icing model.

#### Final Outcome
A donut model with icing and randomly scattered sprinkles. See the reference image.
