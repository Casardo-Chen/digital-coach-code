## Task Name
Create a Responsive Card in Figma

#### Task Description
Build a responsive podcast episode card in Figma using shape tools, image fills, text layers, Auto Layout, constraints, and components. The card should adapt to different sizes while keeping the album art, play button, and metadata visually organized.

#### Learning Objectives
- Create reusable UI elements as components.
- Use frames, shape tools, fills, shadows, and corner radius to build interface elements.
- Add image fills and gradient overlays to improve readability.
- Apply constraints so child elements stay anchored during resizing.
- Use Auto Layout to organize visual content and metadata.
- Configure text resizing and truncation for responsive layouts.
- Set minimum and maximum dimensions to prevent broken responsive designs.

#### Initial State
Empty Figma Design file.

#### Final Outcome
A reusable responsive card component with an image, a constrained play button, metadata text, and Auto Layout behavior that adapts cleanly across different card sizes. See the reference image.
