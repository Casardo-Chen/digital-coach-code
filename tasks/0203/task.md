## Task Name
Add a Falling Animation to a Donut in Blender

#### Task Description
Animate an existing donut model in Blender so it falls downward along the Z axis.

#### Learning Objectives
- Navigate the Animation workspace in Blender.
- Use the timeline to move between frames.
- Set keyframes for an object's transform values.
- Change an object's Z position to create vertical motion.
- Preview a simple animation using timeline playback.
- Understand physics simulation as an alternative way to create falling motion.

#### Initial State
Blender file with a donut and icing model.

#### Final Outcome
A donut model with a simple falling animation that moves downward along the Z axis.
