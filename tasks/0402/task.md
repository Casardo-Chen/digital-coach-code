## Task Name
Create a Melody in FL Studio Piano Roll

#### Task Description
Create a melody in FL Studio using the Piano Roll. The task introduces how to add an instrument, enter and edit notes, shape note timing and dynamics, organize the melody into its own pattern, and place it into the Playlist arrangement.

#### Learning Objectives
- Use the Piano Roll to create and edit melodic notes.
- Add an instrument and choose a preset for melody creation.
- Adjust note length, pitch, timing, and velocity.
- Use selection, movement, copy/paste, zoom, and slide-note controls to refine a melody.
- Separate a melody into its own pattern for cleaner arrangement.
- Add the melody pattern to the Playlist and listen to it with the existing beat.

#### Initial State
Channel Rack beat and Playlist arrangement already created.

#### Final Outcome
An FL Studio project with a separate “Melody” pattern containing a completed Piano Roll melody, added to the Playlist alongside the existing beat arrangement.
