## Task Name
Create a Saddle Bracket in Onshape

#### Task Description
Model a saddle bracket in Onshape from the provided drawing. Start the base sketch on the Top plane, create the main bracket shape, add the center hole, and cut the semicircular saddles on the two upright sides. The part should match the given dimensions and thickness.

#### Parameters:
- Units: inches, lbs
- Material: HDPE
- Thickness: 0.5 in
- Base length: 5 in
- Base width: 3 in
- Overall height: 2.5 in
- Center hole diameter: 1.25 in
- Saddle cut radius: R1
- Key dimensions shown: 2.5, 1.5, 0.5 in

#### Learning Objectives
- Create a simple feature-based part in Onshape.
- Use Center Point Rectangle, Center Point Circle, Offset, Dimension, and Coincident constraint.
- Use Extrude (New/Add/Remove) to build and cut geometry.
- Assign material and check mass properties.
- Maintain design intent so the part can be edited for length.

#### Initial State
Empty OnShape project.

#### Final Outcome
A 3D saddle bracket matching the reference drawing, with a rectangular base, two upright sides, a centered through hole, and semicircular saddle cuts at the top.
