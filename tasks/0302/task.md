## Task Name
Create a Geneva Cam in Onshape

#### Task Description
Model a Geneva cam part in Onshape based on the provided engineering drawing. Start the base sketch on the Front plane with the part center at the origin. Use sketch geometry and circular repetition to define the outer profile, radial slots, and center hub, then build the 3D form with extrusion and feature patterning. The model should follow the specified dimensions and section profile shown in the drawing.

#### Parameters:
- Units: mm, g
- Material: ABS
- Outer reference diameter: 180 mm
- Main body reference diameter: 150 mm
- Hub outer diameter: 75 mm
- Inner hub diameter: 45 mm
- Center hole diameter: 25 mm
- Repeating feature angle: 60 degrees
- Outer profile radius: R30
- Slot width: 12 mm
- Section thickness values shown: 20 mm overall hub region, 10 mm step, 5 mm wall/offset feature
- Tolerance callout shown: ±0.1 mm on the indicated dimension

#### Learning Objectives
- Create a parametric mechanical part from a technical drawing.
- Interpret orthographic, sectional, and isometric views together.
- Build a constrained base sketch on the Front plane centered at the origin.
- Use sketch tools including center point circle, construction line, slot, center point arc, and circular pattern.
- Apply feature tools including Extrude (Add) and Circular Pattern (Feature).
- Model repeated geometry efficiently while maintaining design intent for future revision.

#### Initial State
Empty OnShape project.

#### Final Outcome
A completed 3D Geneva cam model in Onshape that matches the provided reference drawing, including:
- six repeated outer lobes
- six radial slots
- a centered hub with concentric diameters
- the stepped thickness profile shown in Section A-A

The final design check target is:
- Material: ABS
- Mass: 76.468 g
