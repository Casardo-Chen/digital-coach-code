## Task Name
Create a Hub in Onshape

#### Task Description
Model a hub in Onshape from the provided engineering drawing. Build the revolved base profile from the section view, then add the repeated curved slots on the flange face. The part should match the given diameters, lengths, and angular spacing.

#### Parameters:
- Units: mm, g
- Material: ABS
- Mass target: 407.942 g
- Outer diameter: 160 mm
- Slot reference diameter: 128 mm
- Slot end radius: R5
- Angular spacing: 60°
- Section diameters: 100, 75, 55, 45 mm
- Section lengths: 80, 65, 10 mm
- Sketch dimensions shown: 60, 30, 15, 10 mm

#### Learning Objectives
- Interpret a mechanical drawing with top, section, and isometric views.
- Create a revolved part from a section sketch.
- Dimension a profile sketch from engineering parameters.
- Add repeated slot cuts using circular pattern.
- Match flange and hub geometry from the drawing.

#### Initial State
Empty OnShape project.

#### Final Outcome
A 3D hub model matching the reference drawing, with a revolved central body, front flange, center bore, and evenly patterned curved slots.
