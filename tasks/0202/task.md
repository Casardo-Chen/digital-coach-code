## Task Name
Assign Materials to a Donut Model in Blender

#### Task Description
Assign basic materials to an existing donut model in Blender. Starting from a modeled donut with icing, create separate materials for the donut and icing, apply them to the correct objects, and switch to Shading view to preview the result.

#### Learning Objectives
- Locate and use the Material Properties panel in Blender.
- Assign separate materials to the donut and icing.
- Switch from Modeling mode to Shading view.

#### Initial State
Blender file with a donut and icing model.

#### Final Outcome
A donut model with separate materials applied to the donut and icing. See the reference image.
